# Clinic App

A comprehensive clinic management application built using **MongoDB**, **Express**, **React.js**, **Node.js**, **Ant Design**, and **Bootstrap**. It allows users, doctors, and administrators to manage appointments and profiles efficiently.

---

## Features

- **Apply for Doctor**: Users can apply to become a doctor.  
- **Appointment Scheduling**: Users can book appointments with doctors.  
- **Doctors List**: Users can view the list of available doctors.  
- **Appointment Management**: Doctors can approve or reject user appointments.  
- **Profile Management**: Doctors can update their profiles.  
- **Admin Controls**: Admins can approve or reject doctor applications and block users.  

---

## Technologies Used

- **MongoDB**: A NoSQL database for managing data.  
- **Express**: A web application framework for Node.js.  
- **React.js**: A JavaScript library for building dynamic user interfaces.  
- **Node.js**: A JavaScript runtime environment for the backend.  
- **Ant Design**: A UI library for creating visually appealing React applications.  
- **Bootstrap**: A CSS framework for responsive styling.
